Usage

<!-- Basic Table -->
<c-table.container>
  <c-slot name="header">
    <c-table.header_row>
      <c-table.header>Name</c-table.header>
      <c-table.header>Email</c-table.header>
    </c-table.header_row>
  </c-slot>
  <c-table.row>
    <c-table.cell>Alice Johnson</c-table.cell>
    <c-table.cell>alice@example.com</c-table.cell>
  </c-table.row>
</c-table.container>

<!-- Table with Caption -->
<c-table.container caption="Employee Directory">
  <!-- ... table content ... -->
</c-table.container>

<!-- Sortable Table -->
<c-table.container>
  <c-slot name="header">
    <c-table.header_row>
      <c-table.header sortable="true" sort_direction="asc">Name</c-table.header>
      <c-table.header sortable="true">Department</c-table.header>
    </c-table.header_row>
  </c-slot>
  <!-- ... table rows ... -->
</c-table.container>

<!-- Selectable Row -->
<c-table.row selected="true">
  <c-table.cell>Website Redesign</c-table.cell>
  <!-- ... more cells ... -->
</c-table.row>

<!-- Pagination Component -->
<c-table.pagination current_page="1" total_pages="5" />

Attributes

Table Container

Attribute Type Default Description
caption string "" Table caption that provides context about the data
density string "default" Controls the spacing of table cells (compact, default, comfortable)

Table Header

Attribute Type Default Description
sortable boolean false When true, displays sorting controls for the column
sort_direction string "" Sort direction: "asc", "desc", or empty string for no sort

Table Row

Attribute Type Default Description
selected boolean false When true, highlights the row and sets proper ARIA attributes

Pagination

Attribute Type Default Description
current_page number 1 Current page number
total_pages number 1 Total number of pages
rows_per_page number 10 Number of rows per page
rows_per_page_options array [10, 25, 50, 100] Available options for rows per page

Accessibility

  • Tables use proper HTML table semantics with <table>, <thead>, <tbody>, and <caption> elements
  • Table headers use <th scope="col"> for proper association with data cells
  • Sortable columns include accessible button elements with appropriate ARIA labels
  • Selected rows use aria-selected="true" attribute
  • Pagination controls include proper button elements with descriptive labels
  • Tables resize responsibly with overflow scrolling when needed
