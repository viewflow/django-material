Material Design Components

Buttons

Material Design offers several button variants to match your UI needs.

Filled Button (Default)

The standard, high-emphasis button with a filled background.

Default Button With Icon 
{% verbatim %}<c-button.filled>
    Filled Button
</c-button.filled>

<c-button.filled icon="add">
    With Icon
</c-button.filled>{% endverbatim %}

Text Button

A lower emphasis button with no background or elevation.

Text Button With Icon Tertiary 
{% verbatim %}<c-button.text>
    Text Button
</c-button.text>

<c-button.text icon="favorite" color="secondary">
    With Icon
</c-button.text>{% endverbatim %}

Outlined Button

A medium-emphasis button with an outline border and no background fill.

Outlined Button With Icon Tertiary 
{% verbatim %}<c-button.outlined>
    Outlined Button
</c-button.outlined>

<c-button.outlined icon="bookmark" color="secondary">
    With Icon
</c-button.outlined>{% endverbatim %}

Elevated Button

A button with a subtle shadow that provides a raised appearance.

Elevated Button With Icon Tertiary 
{% verbatim %}<c-button.elevated>
    Elevated Button
</c-button.elevated>

<c-button.elevated icon="cloud_upload" color="secondary">
    With Icon
</c-button.elevated>{% endverbatim %}

Icon Button

A compact, circular button that displays only an icon.

{% verbatim %}<c-button.icon icon="settings" aria_label="Settings"></c-button.icon>

<c-button.icon 
    icon="favorite" 
    color="secondary" 
    aria_label="Favorite">
</c-button.icon>{% endverbatim %}
