Django Material

A comprehensive Material Design 3 component library for Django applications.

Component Libraries

touch_app Buttons

Interactive elements for user actions, available in multiple variants.

  • • Filled, Outlined, Text
  • • Elevated, Icon, FAB
  • • Segmented buttons

  • • Elevated cards
  • • Filled cards
  • • Outlined cards

Continuous vertical indexes of text or images for displaying collections of items.

  • • Single-line lists
  • • Two and three-line lists
  • • Avatar and thumbnail lists
