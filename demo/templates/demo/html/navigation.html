Navigation Container

The navigation container is used to structure side navigation with header, content, and footer sections. It provides consistent styling and accessibility features.

dashboard Dashboard
Home Profile Settings Help
account_circle User Profile

Navigation Items

Navigation items are used within the navigation container to create a consistent and accessible menu.

Basic Item

With Icon

Usage

<!-- Basic Navigation Container -->
<c-nav.container>
  <c-nav.item icon="home">Home</c-nav.item>
  <c-nav.item icon="person">Profile</c-nav.item>
  <c-nav.item icon="settings">Settings</c-nav.item>
</c-nav.container>

<!-- With Header and Footer -->
<c-nav.container>
  <c-slot name="header">
    <div class="flex items-center mb-2">
      <span class="material-symbols mr-2">dashboard</span>
      <span class="font-medium">Dashboard</span>
    </div>
  </c-slot>
  
  <c-nav.item icon="home">Home</c-nav.item>
  <c-nav.item icon="person">Profile</c-nav.item>
  
  <c-slot name="footer">
    <div class="flex items-center">
      <span class="material-symbols mr-2">account_circle</span>
      <span>User Profile</span>
    </div>
  </c-slot>
</c-nav.container>
